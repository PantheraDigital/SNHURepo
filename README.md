# SNHURepo

To keep programs maintainable, readable, and adaptable code is written in small, generalized, chunks that have a primary purpose. This is the way of object orientated programming and allows programs to be made of these smaller chunks, but by having code separated like this the chunks can be swapped out, changing functionality or just updating the way the code works. 

The CRUD Python module could be generalized more to work with any database by removing the hard coded variables for database access within the module. That way the module would be given the variables to connect to a database and it would provide the easier to use Create, Read, Update, and Delete functions. 

I approach this project differently from projects in other classes thus far due to the use of technologies I have not used before. I was familiar with python and HTML but not Jupyter, MongoDB, and Dash. Because of this I had to rely more on documentation and figuring out how to get so many different parts working together. My approach was more focussed on the individual pieces rather than the whole project at once. Setting up the database, then getting the database to work in python, then using python to display the data form the database using Dash.
