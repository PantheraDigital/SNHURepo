# What do computer scientists do and why does it matter?
Computer scientists solve problems with computers. This matters as it is what the world is built on today. It would be hard to find any industry, company, or individual that does not use a computer to achieve some task.

# How do I approach a problem as a computer scientist?
I approach problems iteratively and by breaking them down. This is important as it is a reflection  of how programs are made but also allows the problem to be handled one small step at a time, rather than a large singular problem, which results in more efficiency problem solving and the ability to then later apply those solved smaller problems to other future problems. 

# What are my ethical responsibilities to the end user and the organization?
As a computer scientist I am responsible for ethically solving problems for my end users and organizations. This means following rules set by governments but also treating things like personal data with care. If my program requires personal data of a user to work then it is also my responsibility to keep the data protected and private.
