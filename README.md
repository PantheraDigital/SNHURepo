## Reflection
When creating the shapes I took an iterative approach, similar to how I create software. This was also because we worked on this project throughout the class and were introduced to each concept every week. This helped in the making of the 3d scene as it let me focus on one aspect at a time. First getting the objects' shapes right, then camera work, then texturing, then lighting. 

Each milestone was a different part of the scene and a different section of code. One section would load the objects, another would place them in the scene, another would apply textures, and so on. This kept things easy to read, find, and maintain as the project grew. 

We had an established environment to work in that had OpenGL ready to use. Because of this and my experience with programming and game development I ran into no real problems as concepts wee familiar already.
