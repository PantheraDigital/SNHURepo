# SNHURepo

### How can I ensure that my code, program, or software is functional and secure?
Input handling is a very important step in securing a program and improving functionality since input is not guaranteed to be within the expected parameters of the function or class.

### How do I interpret user needs and incorporate them into a program?
User needs get analized then turned into requirements for the program which are used when planning and implementing the program.

### How do I approach designing software?
I initially consider what is required of the system, then plan out the structure and parts of the system. From there I begin implementing while testing along the way to ensure each implemented section behaves as close to expected as it can before further implementation or finishing the system.
